### Project Summary
A **responsive, theme-adaptable portfolio platform** built using a semantic **HTML5** structure and a modular **CSS3** layout pipeline. The interface features a custom structural navigation grid that automatically collapses into an optimized layout for viewports under 768px. 

To improve user engagement, I engineered a **dynamic CSS dark mode engine** using system variables (`:root` properties) paired with smooth 0.3s color transitions. The entire production pipeline is deployed and hosted live via **GitHub Pages** automation workflows.
